# Text Manager - Technical Proof (React + TypeScript + SASS)

Aplicación web desarrollada como prueba técnica para la gestión de elementos de texto, diseñada siguiendo estrictamente las especificaciones de Adobe XD.

## Características Principales

- **Gestión de Listados**: Visualización en tarjeta con scroll interno.
- **Selección Múltiple**: Capacidad de seleccionar varios elementos mediante un clic simple.
- **Eliminación Directa**: Soporte para doble clic en los elementos para borrarlos al instante.
- **Historial (Undo)**: Pila de acciones para deshacer los cambios realizados en la lista.
- **Validación de Formularios**: Vista dedicada para agregar elementos con validación en tiempo real.
- **Estilos Profesionales**: Maquetación adaptada con **SASS** y diseño responsivo de ancho fijo.

## Tecnologías Utilizadas

- **React** (v18+) con **TypeScript**
- **Vite** como empaquetador y entorno de desarrollo
- **SASS** (`.scss`) para los estilos modulares

## Requisitos Previos

Asegúrate de tener instalado en tu equipo:

- **Node.js** (versión 16.0 o superior recomendada)
- **npm** (administrador de paquetes que viene con Node.js)


## Instalación y Configuración del Proyecto

Sigue estos pasos para levantar el entorno de desarrollo en tu máquina local:

**1. Clona el repositorio** (o descarga los archivos en una carpeta de tu elección):

```
git clone https://github.com/naportri/logitravel-technical-proof
cd logitravel-technical-proof/technical-proof-react
```

**2. Instala las dependencias necesarias**:

```npm install```

## Ejecución del Proyecto

Una vez instaladas las dependencias, inicia el servidor de desarrollo local ejecutando:

```npm run dev```

Esto abrirá automáticamente una dirección local (por lo general [http://localhost:**5173**/](http://localhost:**5173**/)) en tu terminal para que puedas visualizar la aplicación en tu navegador.

## Construcción para Producción

Si deseas generar los archivos optimizados listos para desplegar en un servidor de producción, ejecuta:

```npm run build```
